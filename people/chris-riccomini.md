## Why Follow
Chris sits at the exact intersection of **modern data/storage infrastructure** (SlateDB LSMs on S3, Iceberg catalogs, Ibis/DataFusion/Arrow, Substrait, incremental view maintenance) and **pragmatic agentic coding** (`rng.md`: Wiggum loops, Lizard complexity gates, deterministic simulation testing, cached agent output). Almost everything he writes maps directly onto data platform engineering in 2026.

## Signature Mental Models & Themes
- **Quality Gates for Agent-Generated Code:** Enforcing complexity limits (`lizard.py`), lint, security, and tests via `CLAUDE.md`/`AGENTS.md` + Wiggum loops ("The Waymo Rule: AI code just has to beat human error rates under strict gates").
- **Open Source as Cached Agent Output:** Treating OSS libraries as customizable kernels that save tokens and wall-clock time.
- **Zero-Disk / Object-Storage Data Engines:** Building storage engines (SlateDB) and streaming systems natively atop S3/object storage + deterministic simulation testing (DST).
- **Skepticism of unnecessary protocols:** Preferring OpenAPI, CLIs, and static specs over heavyweight MCP servers where simple plumbing works.
