## Why Follow
Simon is one of the most prolific hands-on experimenters in Python, SQLite/Arrow, WebAssembly, and applied LLMs. By subscribing specifically to his `/atom/entries/` feed (rather than `/atom/everything/`), we get only his substantial deep-dives: external Wasm/container sandboxes for coding agents with credential-injecting HTTP allow-list proxies, browser-native Pyodide/SQLite architectures, PR hygiene for AI-authored diffs (`<details><summary>`), and local model experiments.

## Signature Mental Models & Themes
- **External Sandboxes with Network Allow-Lists:** Keep the agent harness outside the sandbox, run untrusted execution inside Alpine/Wasm/Containers, and inject API secrets at the proxy boundary so the agent never sees raw tokens.
- **Human-curated PR openers + `<details>`:** Put human editorial judgment in the top 3 lines of an agent PR and fold the verbose AI walkthrough underneath.
- **URL-addressable data tools:** Packaging SQLite, Arrow, and Python (Pyodide/Service Workers) into zero-backend reproducible links.
